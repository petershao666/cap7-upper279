# Root independent PDF vector verification gate

Object: published Figures 3,4,6,7,8,9 in arXiv:2206.09719v1, representing 45 and named41A-E. This is replication/input verification, not a new construction. No frozen source or producer is modified. Existing H9 did not provide A-E; P EPS decoding is pending independent acceptance.

Root uses PDF vector paths via pdfplumber, independently of P's EPS numeric parser. Shared dependencies are the published figures and their labelled axes. Root has read P's geometric explanation but will not read P's point outputs until its own output is frozen. The labelled axes fix x1 right, x2 up, x3 down-left, x4 right within each plane, x5 up. Recover each figure's outer frame from long vertical strokes and the origin from the median centers/heights of the nine horizontal grid segments in its central cell. The PDF grid lines are slightly offset from marker centers (about 0.375 point horizontally in Figure3). Use a predeclared 0.5-point tolerance, below a tenth of the smallest geometric lattice spacing, without choosing any affine transform or altering coordinates based on cap tests. Derive step u from frame height/30 and use projection (10x1-x3+3x4,-10x2+x3-3x5). Require unique matches among all243 grid positions and require Figure3 exactly equal the already independently accepted 45-cap. Any mismatch stops acceptance.

All filled circular paths must be retained and all recovered points checked with a fresh direct tuple arithmetic kernel: distinctness, all unordered pairs, all242 nonzero normals then divide by2. Read P points only after freezing root output; compare all six pointsets and histograms. One worker, 120seconds, 512MiB. No LP or classification coverage claim here.
